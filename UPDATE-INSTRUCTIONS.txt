HOW TO APPLY THIS UPDATE TO YOUR EXISTING neuroshield-ai-final FOLDER
(It is cumulative: safe to apply even if you already applied the previous update.)

1. Stop both servers (Ctrl+C in each terminal).
2. Unzip over your project folder and choose "Replace". Your .env, data\, artifacts\, .venv and node_modules are not touched.
3. Optional: delete frontend\src\components\ModelBand.tsx (unused).
4. In the VS Code terminal (venv active):
      Set-ExecutionPolicy -Scope Process Bypass
      .\.venv\Scripts\Activate.ps1
      pip install -r backend\requirements-dev.txt      (adds the PostgreSQL driver)
      python -m ml.summarize                           (only if artifacts\reference_profile.json does not exist yet)
5. Restart the backend and the frontend as before.
6. Save your work:  git add -A   then   git commit -m "Add deployment support"
Then follow docs\deployment_notes.md and the GitHub steps in the chat.
